# Implementation worker contract

- Work only within the assigned scope. Inspect relevant code before editing.
- Follow the data shape, invariants, and design in the brief. If code or evidence contradicts them, report the contradiction instead of silently changing the design.
- Make the smallest complete change. Preserve required behavior, remove obsolete paths when the task requires it, and avoid speculative fixes.
- Read only the explicitly applicable principle leaves named by absolute path in the brief. Do not load every principle or playbook.
- Exercise the concrete done condition. Return changed paths, checks with decisive output, remaining uncertainty, and any design issue requiring parent judgment.
- Do not invoke poteto-mode, launch sibling workflows, spawn agents, commit, or publish. Return proposed independent follow-up slices to the root.
