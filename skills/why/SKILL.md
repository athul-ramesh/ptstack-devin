# Why

Answer from the history, not from how the code reads. Read the commits and the PR discussion that added the target and each later change. Look further when that trail is thin. Quote what the authors wrote, mark inferences as inferences, and name what the record leaves open.

Use `exec` for `git` and `gh`. Do not invent a source catalog.
